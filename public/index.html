Questions

Which sites does it handle?

Whatever the current yt-dlp release supports — around a thousand extractors, with reliable coverage of YouTube, X, Instagram, Facebook, TikTok, Vimeo, Reddit, SoundCloud and Twitch. When a platform changes its plumbing, py -m pip install -U yt-dlp fixes the tool.

Where does the file go?

Into ./downloads on the machine running the tool. It is served back over the local address only, and the folder is cleared after six hours. No cloud bucket, no account, no copy anywhere else.

Is downloading legal?

It depends on the work and where you live. Keeping a copy of your own upload, licensed footage or a public-domain film is ordinary. Republishing someone else's video is a different act with a different answer. The rights note walks through the distinction; it is reading, not legal advice.

Why does a link sometimes ask for a login?

Private, age-gated and region-locked posts are only visible to a session the platform trusts. The tool can reuse a browser session you export yourself, but it will never guess credentials or bypass DRM. The failure guide explains the errors you will meet.
